基础排版与正文同步

在保存前预览 Markdown 整理结果；跨稿复用内容时选择具体改动，而不是盲目覆盖。

基础排版

可分别选择首行写入两个全角空格、段落之间增加空行。适用于原稿和全部平台稿。

  • 预览新增和删除的正文行。
  • 确认后写入，写入前保留原文备份。
  • 重复应用不会重复叠加缩进或空行。
  • 标题、代码、列表、引用和表格保留结构。

跨稿正文同步

当某个平台稿中有值得复用的正文修改时，可选择同步目标和具体改动，检查冲突及完整预览后再保存。平台属性与独立配图按规则保留。

同步是经过确认的内容复用，不是自动双向同步。请先核对来源、目标和差异。
