安装与快速开始

安装 EasyPub，确认基础设置，并完成第一篇独立的本地发布稿。首次体验不需要公众号账号、图床或 AI 服务。

环境要求

EasyPub 仅支持桌面版 Obsidian，最低版本声明为 1.5.7。生成本地稿只需 Obsidian Vault；Hexo 需要博客仓库；同步公众号草稿箱需要具备相应接口权限的公众号、AppID / AppSecret 和正确的出口 IP 白名单。

安装插件

  1. 从 GitHub Releases 下载同一版本的三个文件。
  2. 放入当前 Vault 的插件目录：
.obsidian/plugins/easy-pub/\n├── main.js\n├── manifest.json\n└── styles.css
  1. 重启 Obsidian，在「设置 → 第三方插件」启用 EasyPub。
  2. 在「设置 → EasyPub」确认发布根目录，首次体验可保留默认值「发布」。

生成第一篇稿件

  1. 打开一篇普通 Markdown 原稿。
  2. 点击左侧工具栏「打开 EasyPub 发布面板」。
  3. 选择「创建 / 更新发布稿」，再选择目标平台。
  4. 核对标题、作者、摘要等属性，预览变更后确认。
  5. 在 Obsidian 中继续编辑生成的独立稿件。
第一次生成即完成首次体验。公众号本地稿的生成不会写入微信草稿箱。Hexo 自动部署默认关闭。

升级时注意

备份插件目录的 data.json，替换同一版本的三个安装文件。保留自己的 data.json，不要用其他 Vault 的文件覆盖。
