Hexo 博客工作流

将平台稿保存到独立的 Hexo 仓库，处理图片、元数据和预览，再通过受控流程完成部署。

两种输出方式

方式特点适合场景
普通 Markdown（默认）源码易编辑，样式跟随博客主题长期维护博客正文
保留公众号排版生成带样式的 HTML 并引用配套 CSS希望保留当前视觉效果

博客发布步骤

  1. 在 EasyPub 设置中配置 Hexo 仓库绝对路径。
  2. 生成或更新 Hexo 稿，核对图片与元数据。
  3. 在 Obsidian 中编辑保存后的外部 Markdown 文件。
  4. 构建并预览保存版本，确认后再部署。
Hexo 自动部署默认关闭。兼容 Blog Control Room 的博客进入其受保护发布流程；不要将本地预览等同于线上发布。
