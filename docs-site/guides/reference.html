安全、配置与常见问题

了解 EasyPub 的操作边界、凭据处理、升级注意事项，以及遇到异常时应该从哪里开始排查。

发布边界

  • 公众号同步只写入草稿箱，正式发布由用户在微信后台完成。
  • 知乎和小红书生成本地稿，最终由用户自行发布。
  • Hexo 自动部署默认关闭；兼容 Control Room 的博客进入受保护发布流程。
  • AI 排版只提供结构化建议，发送内容需逐次确认。

配置与凭据

公众号 AppID / AppSecret、AI 服务配置、图床配置和博客仓库路径各有独立用途。只配置实际要使用的能力，不要把密钥写入公开文章、截图或仓库文件。

升级与恢复

升级时使用同一 Release 的三个安装文件，保留 Vault 自己的 data.json。重要稿件和插件配置应纳入你自己的备份计划。

常见问题

首次生成公众号稿是否需要账号？

不需要。只有同步微信草稿箱时才需要相应账号与接口权限。

升级时能否删除 data.json？

不要删除。它保存配置、缓存和稿件关联信息。

是否支持手机端 Obsidian？

当前仅支持桌面版 Obsidian，最低版本声明为 1.5.7。
