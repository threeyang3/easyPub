公众号账号配置指南

连接微信公众号前，准备凭据、设置 IP 白名单并完成只读检查。首次生成本地稿不需要配置账号。

先明确：公众号账号配置不是首次生成本地稿的前置条件。只有需要从 EasyPub 同步到微信公众号草稿箱时，才需要连接公众号。

配置前准备

  1. 确认你有权管理目标微信公众号。
  2. 在公众号后台获取 AppID 和 AppSecret。
  3. 确认账号具备所需的素材与草稿接口权限。
  4. 准备当前网络的公网出口 IP，并在公众号后台配置 IP 白名单。

从哪里打开配置向导

有两种入口：

  • 在公众号工作台右上角，首次使用时点击「连接公众号」。
  • 在 Obsidian「设置 → EasyPub → 微信公众号」中点击「引导配置公众号」。

填写账号信息

  1. 输入公众号 AppID。
  2. 输入对应的 AppSecret。
  3. 可选填写默认作者；它只为尚未设置作者的本地稿提供默认值。
  4. 点击「保存并继续」。

配置公网 IP 白名单

白名单应填写微信服务器实际看到的公网出口 IP，而不是电脑的局域网地址、路由器管理地址或 VPN 虚拟网卡地址。

  • 如果使用代理、VPN 或公司网络，出口 IP 可能与浏览器查询到的地址不同。
  • 浏览器与 Obsidian/Electron 请求可能经过不同的代理路径。
  • 如果返回 IP 白名单错误，应先确认 EasyPub 请求实际使用的出口 IP，再更新公众号后台白名单。
不要把 AppSecret、完整配置文件或带密钥的截图发到公开 issue、聊天记录或仓库。

运行只读连接检查

保存后点击「运行只读检查」。向导会分别显示令牌获取、素材读取和草稿读取结果。

检查项目含义
令牌获取检查 AppID、AppSecret 与网络访问是否可用。
素材读取确认素材相关读取接口是否可用。
草稿读取确认草稿列表读取权限和接口状态。

显示「连接检查通过，可以返回编辑」代表只读检查通过。图片上传和草稿写入仍需在首次实际同步时验证；这不是只读检查能够保证的事项。

密钥保存与安全

  • AppSecret 优先通过系统加密能力保存。
  • 如果系统加密不可用，密钥可能仅保留在当前插件会话，重启或重载后需要重新输入。
  • 已有账号修改配置时，密钥留空可保留原密钥。
  • 切换 AppID 时必须提供新账号对应的密钥；旧账号密钥和会话密钥会清除。
  • 访问令牌仅缓存在内存，不要手动复制或分享。

代理与常见错误

  • IP 白名单错误：确认公网出口 IP 与请求实际代理路径。
  • AppID / AppSecret 错误：核对是否来自同一个公众号，避免复制空格或换行。
  • 令牌获取失败：先确认网络连通性、账号状态和凭据，再重新运行检查。
  • 素材或草稿读取失败：确认接口权限，不要把令牌成功等同于所有接口均有权限。

配置完成后

  1. 返回公众号工作台。
  2. 检查本地稿正文、文章信息、图片和封面。
  3. 解决工作台显示的同步阻塞原因。
  4. 首次同步时观察图片上传和草稿创建结果。
  5. 同步成功后，到微信后台及手机预览检查，并由你自行正式发布。
