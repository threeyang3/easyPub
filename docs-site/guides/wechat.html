微信公众号工作台

在 Obsidian 中完成公众号本地稿，检查正文、文章信息、图片和封面，再按需同步到微信草稿箱。

首次连接公众号？先阅读「公众号账号配置指南」→

工作台包含什么

  • 正文预览：检查当前绑定的公众号本地稿。
  • 文章信息：维护标题、作者、摘要等文章属性。
  • 图片与封面：管理正文图片以及横版 2.35:1、方形 1:1 封面。
  • 同步草稿箱：检查通过后将文章同步到微信公众号草稿箱。

推荐操作顺序

账号首次配置请参阅公众号账号配置指南，已配置账号可直接进行连接检查。

  1. 编辑本地 Markdown 稿件。
  2. 检查正文预览、文章信息和图片。
  3. 需要时进入主题与智能排版，预览并保存。
  4. 配置账号并运行只读检查，处理同步前提示。
  5. 同步到草稿箱后，到微信后台及手机预览检查，再自行正式发布。
重要：同步草稿箱不等于正式发布。EasyPub 不执行公众号群发。
