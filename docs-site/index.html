几分钟，生成第一篇本地稿

  1. 01

    下载并安装

    从 Releases 下载同一版本的 main.js、manifest.json、styles.css，放入 Vault 的 .obsidian/plugins/easy-pub/。

  2. 02

    启用并打开发布面板

    重启 Obsidian，在「设置 → 第三方插件」启用 EasyPub，点击左侧工具栏的发布面板入口。

  3. 03

    选择平台并确认属性

    点击「创建 / 更新发布稿」，选择平台，核对标题、作者、摘要等属性，预览变更后确认生成。

  4. 04

    编辑独立稿件

    公众号会打开工作台，其他平台打开对应 Markdown 文件。本地稿生成后即可继续编辑。

常见问题

第一次使用必须配置公众号账号吗？

不需要。生成和编辑公众号本地稿可以完成；只有同步微信草稿箱时才需要配置具备相应接口权限的账号。

EasyPub 会自动把文章发布到公众号吗？

不会。插件可同步到草稿箱，正式发布仍由你在微信后台检查并操作。

升级时要删除 data.json 吗？

不要。替换同一版本的三个安装文件，并保留自己的 data.json。

支持手机端 Obsidian 吗？

当前仅支持桌面版 Obsidian，最低版本声明为 1.5.7。
