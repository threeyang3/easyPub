## 后续更新

1. 先确认当前稳定版的入口、按钮文字和操作行为，再准备不含个人信息的演示文章。
2. 在实际插件或加载实际组件的演示宿主中进入目标状态；每张图只说明一个操作重点。
3. 保留窗口标题、选择项、预览与确认按钮，裁去无关侧栏和大块空白。需要解释局部时，另加局部图，不改变产品内容。
4. 在文档正常显示宽度检查文字是否可读、图片是否完整，再替换同名图片并更新此表。截图更换无需提升插件版本。

浏览器捕获遵守项目的浏览器执行约束，使用 ChatGPT 内置浏览器；不启动本机 Chrome 或 Chromium。
