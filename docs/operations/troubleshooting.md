# 故障排查

[文档首页](../README.md) · [恢复指南](backup-and-recovery.md) · [配置参考](../reference/configuration.md)

先确认插件版本或开发 commit、Obsidian 版本、当前绑定稿路径，以及你执行的是本地生成、预览、远端草稿同步还是正式部署。不要把按钮名中的“发布”一律理解为公开上线。

## 安装、路径与稿件

| 现象 | 优先核对 | 下一步 |
| --- | --- | --- |
| 看不到新命令/按钮 | Vault 中是否安装了同次构建三个文件，插件是否重载 | 按[升级步骤](../getting-started.md)核对，不只替换 main.js |
| Hexo 提示路径无效 | 是否填写本机绝对仓库根目录，是否有 `_config.yml` | 修正路径；不要填写 URL 或 `_posts` 子目录 |
| 博客稿不在 Obsidian 文件列表 | 它位于 Vault 外，当前并未挂载 | 用系统编辑器/后台打开，或使用 EasyPub 真实主题预览 |
| 原稿更新了但预览没变 | Hexo 预览显示已保存博客稿；公众号显示固定本地稿 | 主动更新相应发布稿，再刷新 |
| 同名文件产生编号 | 同名目标不属于同一 pub_id | 核对身份，编号是防覆盖行为，不要强行覆盖 |
| ID 冲突/多个目标 | 复制源稿沿用了 ID，或同平台有多份同 ID 文件 | 执行只读目录检查；先确定真实归属，再人工修复 |
| Front Matter 无法解析 | YAML/JSON 语法、目标目录中的其他损坏稿件 | 修复报告中的文件，不跳过它来强行发布 |
| 稿件已保存但打不开 | 外部系统编辑器关联或宿主打开失败 | 按提示路径打开，不因打开失败重复发布 |

批量补齐 ID 只补缺失值，不会自动修复配对关系。复制文章作为新稿时，需要核对并处理副本的旧关联，不能删除原文章身份来消除冲突。

## Hexo 与后台

| 现象 | 排查 |
| --- | --- |
| 找不到 node / Hexo | 安装系统 Node，重启 Obsidian；在博客目录安装本地依赖；Mac 见[迁移指南](../macos.md) |
| 配置错误且没有执行 clean | 预检保护；修复完整 YAML 与 deploy.type |
| 部署按钮只打开后台 | 兼容 Control Room 的预期行为，在后台继续 |
| 后台不兼容或会话无效 | 核对固定脚本、会话格式、绝对路径；不要手工复制带令牌 URL 到 issue |
| Linux 未自动启动后台 | 当前需在博客目录运行 npm run gui，再重试打开 |
| 文章预览被拒绝 | 核对配套后台版本、pub_id 唯一性、有效 abbrlink 和固定回环 5001 地址 |
| 加密文章未出现在本地主题预览 | 预览排除加密文章，不表示正式加密构建成功 |
| 发布锁文件残留 | 先确认没有活动发布进程，再按报错路径处理；不要并行删除锁强行运行 |

后台端口和站点预览端口不同：管理会话端口由后台决定，文章预览固定为 `127.0.0.1:5001`。不要把其他本机服务的地址当成可信预览。

## 公众号与排版

| 现象 | 排查与恢复 |
| --- | --- |
| 连接检查通过但同步失败 | 只读检查不验证图片上传和草稿写入权限；看本次具体错误 |
| IP 白名单错误 | 使用微信接口实际看到的公网出口，代理和浏览器不一定同路径 |
| 同步按钮不可用 | 检查预览是否过期、设置是否未保存、图片/封面是否失败、任务是否忙碌 |
| 切换源笔记后工作台仍是旧稿 | 固定绑定的设计；核对路径，通过目标本地稿重新打开 |
| 网络图片不下载 | 核对是否为仅 Vault 附件模式、URL 限制、超时/大小或宿主流式接口 |
| GIF/动画不支持 | 导出静态 PNG/JPEG，保留原图；不依赖自动取首帧 |
| 正文或排版超限 | 减少重点组件、使用更简洁主题或拆分文章；比较默认模板不会使超限方案可保存 |
| AI 请求按钮不可用 | 可能无可靠区块映射，或请求/保存正在进行；本地主题仍可用 |
| AI 配置失败 | 核对完整接口路径、模型、JSON 模式和密钥；不要把 Key 放进 URL |
| AI 结果无效/过期 | 原文、设置或手工方案已变化，或响应不符合 schema；重新预览/准备请求 |
| 本地排版已应用但微信未变化 | 应用只保存本地元数据，须单独同步草稿箱 |
| 后台有修改导致冲突 | 先比较本地和远端；默认取消，按需要另建或明确覆盖 |
| 不确定写入状态 | 不反复新增、不删除状态；查询草稿并确认恢复关联 |
| 回读一致但显示异常 | 后台和手机分别检查；接口文本与浏览器视觉并不等价 |

超时不一定表示远端没有处理。已提交的微信写入和已发送的 AI 请求可能继续完成，详见[恢复指南](backup-and-recovery.md)。

## 配置和凭据

“设置读取失败，保存锁定”不能通过继续改普通设置修复。使用重新读取，或明确确认备份后重置。磁盘写入失败时，当前会话设置可能与重启后的配置不同。

跨设备不可解密时重新输入密钥；不要清空整个 data.json 来修复单个认证错误，否则可能丢失草稿关联与恢复状态。

## 如何提交可复现的问题

提供合成的最小 Markdown、操作步骤、预期/实际结果、插件版本/commit、操作系统与 Obsidian 版本，以及必要的脱敏截图。注明是否涉及真实远端写入、最后一次已知成功步骤和是否处于 uncertain 状态。不要附完整 data.json、会话文件、密钥或私人文章。
