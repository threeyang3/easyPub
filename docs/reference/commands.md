# 命令与界面入口

[文档首页](../README.md) · [配置参考](configuration.md) · [发布机制](../publishing.md)

命令由 [main.ts](../../main.ts) 注册。命令面板通常显示 `EasyPub: <名称>`；内部完整 ID 为 `easy-pub:<命令 ID>`。显示名以当前代码为准，部分名称保留英文。

## 全部命令

| ID | 名称 | 从哪里执行 / 行为 |
| --- | --- | --- |
| `open-publishing-panel` | `打开发布面板` | 随时打开常驻侧栏，无文章时也能使用常用工具 |
| `format-hexo` | `一键排版 Hexo 发布稿` | 从原稿定位 Hexo 稿；预览补空行和空白清理，确认后备份并保存 |
| `publish` | `Publish to platform` | 当前源 Markdown；选平台后生成或确认更新稿件。公众号已有本地稿时只打开 |
| `initialize-source-properties` | `初始化原稿属性` | 当前原稿；填写基础属性并预览，确认后补齐缺失 ID；保留自定义属性 |
| `refresh-platform-properties` | `从原稿刷新平台属性（选择字段）` | 当前原稿；选择已有平台稿及要刷新的字段，可预览并选择清理旧额外属性；保留目标正文与首次日期 |
| `build-hexo` | `Build Hexo locally (no deploy)` | 使用设置中的博客仓库执行 clean + generate，不部署；构建成功后尝试更新当前文章发布链接 |
| `deploy-hexo` | `Deploy to Hexo` | 普通仓库执行 Hexo 构建/部署；兼容后台则打开保护流程 |
| `open-hexo-control-room` | `Open Hexo management console` | 打开设置中的兼容博客后台，不要求当前文件是文章 |
| `preview-hexo` | `预览 Hexo 发布效果` | 从带 pub_id 的源文章定位已保存博客稿，展示兼容后台生成的真实主题页面 |
| `wechat-setup` | `引导配置微信公众号` | 打开账号配置向导；明确保存后生效，可执行只读连接检查 |
| `wechat-preview` | `预览并同步公众号草稿` | 当前文件须为公众号本地稿；打开工作台，本命令本身不向微信写入 |
| `wechat-refresh-source` | `从源文章更新公众号本地稿（确认后替换正文）` | 当前源文章；已有稿件差异确认后替换正文，保留其 wechat 设置 |
| `fill-missing-pub-ids` | `批量补齐文件夹中的 pub_id` | 打开范围选择；确认后为目录中的缺失 ID 写入新值，不自动配对源稿与发布稿 |
| `check-publish-directory` | `检查发布目录（只读）` | 选择平台并扫描缺失/重复 ID、不可读和损坏元数据；不修改稿件 |

## 功能区和设置页

- 面板“打开 EasyPub 发布面板”图标：打开常驻侧栏，提供顶部 Hexo 管理后台快捷键。
- 云形 `Publish` 图标：等同发布命令。
- 仪表盘“打开博客管理后台”：等同打开 Control Room。
- 设置页“预览当前文章”：仍需要当前源文章的关联，不会预览尚未保存到博客的源正文。
- 设置页“查看备份”：只读浏览原文与来源；“检查备份”：统计及 Git 状态检查，不自动删除或恢复。
- 设置页“配置 AI 排版”：只保存服务配置，不会自动发送文章。
- 设置页“本地发布稿 → 文章属性”：提供初始化当前原稿、刷新平台属性的入口。

## 公众号工作台按钮

| 操作 | 结果与副作用 |
| --- | --- |
| 刷新预览 / 暂停刷新 | 读取本地稿与附件；允许网络图片时可能下载图片，不上传微信素材 |
| 打开本地稿 | 打开固定绑定的文件，不随当前编辑器切换同步目标 |
| 信息、配图与封面 | 编辑文章设置、查看图片和裁剪；保存后写入本地稿元数据 |
| 智能排版 | 本地预览与组件调整；“应用”只写入本地稿的方案和历史 |
| 准备 AI 排版请求 | 展示地址、模型和完整请求内容，不联网 |
| 确认发送这些片段并生成方案 | 调用配置的 AI 服务，可能产生服务费用；不会自动应用或同步微信 |
| 同步草稿箱 | 检查配置及素材，按需上传图片，创建或更新微信草稿 |
| 查询 / 恢复关联 | 查询远端草稿；确认后更新本地关联状态，不自动覆盖远端正文 |
| 打开公众号后台 | 使用系统浏览器打开微信后台，发布由用户完成 |

“发布”是入口名称，不表示所有平台会立即公开内容。具体边界以[项目概览](../overview.md)的能力矩阵为准。
