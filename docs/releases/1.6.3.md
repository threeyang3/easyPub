# EasyPub 1.6.3

本版集中改进发布安全、异常诊断和备份维护，保持 Obsidian 1.4.4+ 桌面端兼容，不要求迁移旧文档或配置。

- 损坏的发布稿会集中列出路径；无法排除 ID 冲突时停止，不静默跳过或改写。
- 源稿关联写回前复查快照，修改回调内核对源路径、ID 和关联，避免并发修改被覆盖。
- 使用会话内身份索引，减少重复读取未变化笔记；冲突候选仍实时读取。
- 设置新增“检查备份”，展示数量、占用空间、路径和 Git 忽略状态。首次覆盖博客稿件前提醒全文备份可能包含未公开内容。
- 备份检查识别已跟踪文件，不自动修改忽略规则、取消跟踪或删除历史备份。

备份位于博客根目录 `.easy-pub-backups/`。建议在博客 `.gitignore` 中忽略该目录；已经被 Git 跟踪或推送的备份需另外处理，新增忽略规则不能撤回历史。

验证：完整核心/微信测试、微信浏览器回归、TypeScript 检查及生产构建。真实公众号写入未在本次重新执行，微信接口行为未改动。协作锁不能完全阻止外部编辑器竞态，源稿与目标稿仍不是跨文件事务。

安装：下载同一版本的 `main.js`、`manifest.json`、`styles.css`，替换插件目录中的对应文件并重新加载插件。
