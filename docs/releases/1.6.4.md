# EasyPub 1.6.4

本版补齐 macOS 发布环境支持，增加 Hexo 真实主题预览，并改进发布检查、备份和图片处理。

- macOS 下补充常见 Node/Git 路径；兼容的博客管理后台可自动启动并复用已验证会话。
- 在 Obsidian 内预览 Hexo 已保存稿件，查看文章顶部图、首页封面和手机布局。需要支持文章预览接口的博客管理后台。
- Hexo 封面和顶部图支持 Vault 附件，沿用正文图片复制或 PicGo 流程。
- 增加发布目录检查和历史备份查看，改进稿件身份核对与写入保护。
- 改进 PicGo 凭据保存与非本机 HTTP 上传确认；改进公众号网络图片的下载限制、超时中止和权限切换处理。
- 完成 Mac Sandbox 真实公众号草稿创建、同 ID 更新、图片与封面上传、素材复用及插件重载恢复验收。测试范围与未完成项见公众号验收记录。

公众号仍使用内置默认排版模板，本版未增加 AI 排版。

安装或更新：从本次 Release 下载 `main.js`、`manifest.json` 和 `styles.css`，放到 Vault 的 `.obsidian/plugins/easy-pub/` 中，再重新加载插件。三个文件须来自同一版本。最低 Obsidian 版本仍为 1.4.4。
