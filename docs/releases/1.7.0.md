# EasyPub 1.7.0

公众号新增保真智能排版：十二套可视风格预设，以及由用户配置服务的 AI 语义规划。文字、代码、图片和顺序仍来自本地稿，应用排版和同步草稿箱分别确认。

- 风格画廊、导语与重点卡片、引用与总结组件，支持逐块调整、锁定、撤销、候选、历史和缓存。
- AI 仅返回严格校验的 LayoutPlan；发送前预览目标与片段，凭据加密或只保留会话，过期响应不会覆盖新稿。
- 配置读取失败时锁定常规保存，支持验证备份后重置，保护账号和草稿关联。
- Hexo 预览兼容历史短链接，需配套博客后台更新。
- 修复微信代码块换行折叠，增加同步回读差异提示。微信可能移除普通外链并保留链接文字。

验证：Mac Sandbox 真实模型及公众号草稿创建/更新、素材复用、冲突取消与另建均通过；用户确认朱砂书卷的后台和手机预览正常。十二套风格经过自动化及原生宿主保真检查，其余风格不据此宣称逐套手机验收。完整记录见[实施与验收](../wechat-layout-acceptance.md)。

从本次 Release 下载同一版本的 `main.js`、`manifest.json`、`styles.css`，复制到 Vault 的 `.obsidian/plugins/easy-pub/` 后重新加载插件。保留原有 `data.json`。最低 Obsidian 版本仍为 1.4.4。
