# EasyPub 1.7.2

本次更新改善发布稿查找与排版工作台，修复异步取消和保存互斥，并补齐项目文档。

- 本地平台发布稿移入发布目录的子目录后，仍可按 pub_id 找回；保留身份检查、差异确认、备份和原子写入。
- 排版窗口读取、打开和保存过程中检查关闭状态与版本；阻止重复窗口和并行保存。应用使用独立方案及历史快照，取消检查延伸到宿主元数据回调，失败重试不会误增历史。
- 本地风格与可选 AI 分组，明确对比、撤销和保存状态；窄窗口可切换编辑与预览，底部操作保持可见。普通设置增加保存反馈。
- 拆分发布存储与平台选择模块，统一长度及组件角色规则，收紧博客预览样式作用域。
- 重建 README 和文档中心，补齐概览、四张架构/流程图、使用与开发指南、配置/数据参考、安全、排障、备份和发布流程。

验证覆盖核心测试、生产构建、公众号与发布弹窗浏览器回归；优化阶段 macOS Obsidian 38 项原生检查通过。文档本地链接/锚点检查通过，四张 Mermaid 图在 Sandbox Obsidian 实际渲染成功。PR 与最终主分支构建状态以 GitHub CI 为准。

本轮没有重新调用真实 AI 或写入微信草稿箱，也没有正式发布文章。后台与手机的既有验收范围及尚未覆盖的宿主环境见[版本状态](../status.md)。

升级请一起替换本 Release 的 `main.js`、`manifest.json`、`styles.css`，保留并备份原 `data.json`，然后重载插件。无需迁移文章 ID；最低 Obsidian 版本仍为 1.4.4，仅支持桌面端。安装新包不会自动同步远端草稿。
