# EasyPub 1.7.3

本次更新优化公众号长文预览与草稿同步性能，并加强异常恢复。

- 区块排版映射由逐块宿主渲染改为单次批量渲染，最长文章最多 300 个区块也只调用一次 Markdown 渲染器。
- 图片源校验由每张图片上传时重复检查全部图片，改为每张图片在上传前及草稿写入前各检查一次，避免长文同步形成近似 O(n²) 的读取或下载。
- 复用 Markdown AST 解析结果，减少重复解析；DOM 完整性指纹改为单次线性遍历和 SHA-256，降低临时内存压力。
- 图片占位符改为单次扫描替换，并移除重复 HTML 长度检查与排版对比中的冗余渲染。
- 预览安装后发生 UI 异常时释放图片资源并恢复待刷新状态；同步结束按原状态恢复控件。

验证覆盖核心与布局单元测试、公众号工作台和发布弹窗浏览器回归，以及 macOS Obsidian 38 项原生检查。本轮未调用真实 AI、未写入微信草稿箱，也未执行正式文章发布。

升级请一起替换本 Release 的 `main.js`、`manifest.json`、`styles.css`，备份并保留原 `data.json` 后重载插件。最低 Obsidian 版本仍为 1.4.4，仅支持桌面端。
