# EasyPub 1.8.0

本次更新让原稿保存基础信息，各平台发布稿独立维护自己的属性，并提供初始化与属性刷新向导。

## 新增与改进

- 新增“初始化原稿属性”：填写标题、作者、摘要、标签、分类、封面及可选日期，预览确认后写入；缺失的 `pub_id` 自动生成，已有 ID 与自定义属性保留。
- 首次生成平台稿时，按该平台白名单继承基础属性并显示设置表单。原稿的其他笔记属性及其他平台专用属性不再自动复制。
- 后续更新正文时保留平台稿的标题、标签、摘要、封面和专用设置。
- 新增“从原稿刷新平台属性（选择字段）”：逐项选择字段并预览，保留平台稿正文、首次日期及关联身份。
- 旧稿额外属性默认保留，可在属性刷新窗口选择清理；最终差异确认后才写入。
- 公众号标题统一保存到顶层 `title`。兼容读取旧 `wechat.title`，确认保存时迁移并保留原展示标题；作者、摘要、封面仍保存在 `wechat` 中。
- 公众号封面更换后清除旧裁剪；本地封面路径按平台稿位置转换。设置页增加属性操作入口。

## 升级后的行为变化

更新原稿正文后，各平台稿的同名属性不再随之覆盖。需要同步标题、标签或封面时，请从原稿执行“从原稿刷新平台属性（选择字段）”。

知乎类型在首次生成表单中选择；已有稿件刷新 `zhihu_type` 不自动移动文件。原稿与旧稿不执行批量属性清理。完整字段与继承规则见[数据模型](../reference/data-model.md#属性归属)。

## 验证与安装

验证覆盖核心测试、TypeScript 检查、生产构建，以及发布弹窗和公众号工作台两套浏览器回归，包含初始化取消、源稿并发变化、选择性刷新、属性清理、标题迁移和排版保存。本轮未请求真实 AI 或写入微信草稿箱；最低宿主版本与 Windows/Linux 原生交互仍需独立验收。

升级请备份并保留原 `data.json`，一起替换本 Release 的 `main.js`、`manifest.json`、`styles.css`，然后重载插件。最低 Obsidian 版本仍为 1.4.4，仅支持桌面端。
