# EasyPub 1.9.2

1.9.2 改进新建文章时的原稿属性填写，并让插件端与博客后台的标签格式规则保持一致。

- “新建文章”可选择 Vault 中已有目录，也可填写仓库内自定义相对目录。
- 标签和分类显示已有元数据建议，标签支持逐行添加自定义值。
- 标签输入会提示逗号分隔错误，并拒绝包含逗号或超过 60 个字符的单项。
- 原稿创建、原稿属性初始化，以及 Hexo、知乎、小红书和微信公众号稿件属性窗口复用相同建议和校验逻辑。
- 同名原稿自动编号，目录安全检查和平台发布目录隔离规则保持不变。

验证范围：`npm test`、`npm run check`、`npm run build`。未执行真实微信写入、图床上传或博客部署；这些动作仍由各自平台流程单独确认。
