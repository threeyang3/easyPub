# EasyPub 1.9.4

1.9.4 新增公众号稿的 Hexo 输出选择，以及原稿和各平台稿的基础排版工具。

- 公众号工作台「生成 Hexo 稿」默认输出普通 Markdown，直接使用当前公众号本地稿正文。本地图片复制到博客，远程图片保留网址，图片标题和代码内容保持完整。
- 可选择「保留公众号排版」，将当前预览导出为带内联样式的 HTML，并引用独立 CSS。两种方式都先展示正文与差异，再确认保存；已有同篇 Hexo 稿保留原位置和博客属性，不自动部署。
- 原稿及 Hexo、知乎、公众号、小红书稿均提供「基础排版」：可分别选择首行写入两个全角空格、普通正文行间加空行。仅保存当前稿件，不自动同步其他稿；重复执行不叠加缩进或空行。
- 基础排版保留标题、代码、列表、引用、表格等结构，保存前展示差异并备份原文；正文、路径或编辑器内容变化后需要重新预览。
- 两处新窗口采用选项侧栏、正文预览和固定页脚。差异行有增删标记，可切换全文对照；排版规则与备份位置默认收起，界面沿用 Obsidian 明暗主题并适配窄窗口。

无需配置或文章迁移。最低 Obsidian 版本仍为 1.5.7，仅支持桌面端。基础排版选项会直接修改 Markdown 正文；公众号主题排版仍保存为文件头配置。

本地核心测试、TypeScript 检查与生产构建通过；应用内浏览器使用真实组件和测试夹具核对明暗主题、520px 窄窗口、格式切换、全文对照及取消操作。候选包已安装到 macOS Obsidian 1.14.5 的 Sandbox，确认基础排版窗口、全文对照与取消操作正常，原配置保持字节一致，未捕获运行错误。远端三平台构建与完整浏览器检查以本次提交的 GitHub Actions 为准，最终附件以同版本 Release 为准。

本轮本地验证未执行真实微信写入、图床上传、博客部署、最低宿主版本或 Windows/Linux 原生 Obsidian 验收；插件重载不代表完整退出重启验收。

安装时下载本 Release 的 `main.js`、`manifest.json`、`styles.css`，一起替换 Vault 中 `.obsidian/plugins/easy-pub/` 下的对应文件并重载插件，保留原有 `data.json`。
