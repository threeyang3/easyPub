## 本机开发构建（尚未发布独立 Release）

2026-10-29 的工作区改进包括：Obsidian 原生 Hexo 稿件打开与博客目录图片粘贴；跨发布稿选择正文改动或新增独立配图、冲突与完整正文预览；公众号主题、配色及唯一未变区块样式保留。操作见[发布面板](publishing-workbench.md)与[公众号排版](wechat-layout.md)。

核心测试、TypeScript 与生产构建通过；Sandbox 原生 Hexo 编辑验收和跨稿同步窗口验收通过。跨稿验收覆盖从 Hexo 到公众号的配图导入、独立正文/元数据保留、区块锁定、后续同步基准及默认附件设置不变。未执行真实微信写入、图床上传、博客部署或 Windows/Linux 原生验收。稳定 Release 版本信息仍以下节为准。

## 版本边界

- 本次版本：[1.9.1 Release](https://github.com/threeyang3/easyPub/releases/tag/1.9.1)，对应[发布说明](releases/1.9.1.md)。发布状态及最终提交以 GitHub Release 为准。
- 1.9.1 改进稿件定位索引、公众号预览复用、AI 排版异步交互和发布面板刷新；修复 Windows 换行的改动视图。最低 Obsidian 1.5.7、桌面端限定保持不变，既有 1.9.0 发布包保留。
- 1.9.0 新增常驻发布面板、Hexo 一键排版和附件导入，重构公众号工作台与独立双比例封面裁剪。最低 Obsidian 版本提高到 1.5.7（附件路径 API）；已发布 1.8.0 的最低版本仍为 1.4.4，历史映射保留。
- 1.8.0 新增原稿初始化、平台字段白名单、按字段刷新与旧属性清理、公众号单一标题；详见[属性归属](reference/data-model.md#属性归属)。
- 发布稿的属性后续独立维护；更新正文不再自动覆盖标题、标签和封面，需通过专门命令选择字段刷新。旧稿额外属性默认保留，不批量迁移文章。
- 安装时使用同一 Release 的三个附件；1.8.0 不包含本轮工作台、排版与附件导入改进。

- 完全退出并重新启动宿主后的系统加密持久化与账号恢复；插件重载不能代替该步骤。
- 最低 Obsidian 版本，以及 Windows/Linux 的原生交互、路径和系统加密行为。
- 更多主题在真实后台和手机上的显示；微信客户端升级后仍需抽样复验。
- 结构/异步修复之后的新一轮真实 AI、草稿创建更新及配套后台联调。
- 正式发版前最终合并提交、CI、下载附件一致性和测试 Vault 安装检查。
