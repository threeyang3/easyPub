## 1.9.3 改进与验证记录

基于 `41ffae7` 核验并改进发布面板单次查找打开、同步阻塞原因展示、属性列表与变更预览。以下改进随 1.9.3 发布，不属于 1.9.2 Release 附件。

核验结论：

- 发布面板原有“检查 → 打开”确需两次点击，现合并为“查找并打开”；未找到时仍需用户点击创建，打开失败后回到查找状态。正文保存不新增平台扫描。
- 工作台原有同步禁用条件集中在 `updateSyncState`，现由同一组原因驱动禁用状态、提示及解决入口；远端写入协议不变。
- 标签原本已支持逐行输入，并非必须手写 JSON。此次让常规列表初始化和候选项回填也采用逐行文本；多路径分类与不适合逐行表示的值保留 JSON，避免改变数据。候选项增加搜索，每次最多显示 20 项。属性预览展示保留、修改、清空与移除，完整数据仍可展开查看。
- 版本边界中残留的“本次版本 1.9.1”已删除；当时稳定版本为 1.9.2。
- `package-lock.json` 已提交，CI 已使用 Node 20；`obsidian: latest` 是升级策略问题，不能据此认定锁定安装不可复现，本轮不调整依赖。
- `wechatSync.ts` 已在远端写入前持久化 uncertain 状态，并阻止未经核验的再次写入；不得把报告中的建议误读为现有流程没有此保护。
- 多布尔状态和跨文件非事务操作属后续维护风险；本轮未证实数据损坏、凭据泄露、内存泄漏或必须全局重构的缺陷。未引入任务协调器、事务日志或新状态机。

本轮验证：核心测试及生产构建通过；JSDOM 覆盖单次查找打开、失效后重查、同步原因组合、候选搜索及属性预览；应用内浏览器使用真实组件与测试夹具验证信息编辑后同步禁用、保存后恢复以及列表变更表。按本机浏览器规则未启动 Chrome/Chromium，因此未执行原有两套完整 Playwright 浏览器脚本。未做真实微信写入、博客部署、完整重启、长期内存或跨平台宿主验收。

### 2026-11-02 Sandbox 安装与原生验收

在 macOS Obsidian 1.14.5 / Electron 43.7.7 的 Sandbox 安装 `12f1415` 后，发现恢复的公众号标签页可能仍是宿主延迟加载占位视图，直接调用 `bind` 会失败。本次修复在绑定前调用可选的 `loadIfDeferred`，兼容旧版已立即加载的宿主；已补回归、构建并重新安装。远端验证以包含本次修复的提交 CI 为准，不能沿用 `12f1415` 的 CI 结论。

原生组件操作、DOM 断言及真实文件核对共 24 项通过，覆盖发布面板单次打开/缺稿不自动创建/固定上下文、属性预览/修改后重新确认/保存/取消，以及本地封面/标题保存与同步阻塞恢复。插件设置文件保持字节一致，未执行微信远端写入、博客部署或发版。原生输入与截图捕获有延迟，本轮不声称完成全程鼠标键盘走查。详见[验收记录](verification/workbench-native-20261102.json)。
