## 真实账号发现与修复

- 研究主题、活动主题、重点卡片样式均在草稿接口回读中保留；标题、段落、嵌套列表、引用、表格、代码和链接可见文字保持原顺序，原 Markdown 正文哈希不变。
- 当前测试账号会移除 GitHub 外部链接的 `<a>`，但保留文字。插件新增同步后诊断，明确提示实际链接改写，不能将 API 写入成功当作链接可点击的保证。
- 微信把正文图片的 `src` 改成 `data-src`，将 HTTP 原图 `/0` 转为 HTTPS `/640` 规格。回读诊断按受控微信 CDN 的素材标识比较，只忽略已知规格和 `from`/`wx_fmt` 参数；不同素材、未知参数、数量或顺序仍会提示差异。
- 未进行群发或正式发布。测试草稿保留为“EasyPub智能排版验收-可删除”。原始本机证据不包含在公开仓库中。
